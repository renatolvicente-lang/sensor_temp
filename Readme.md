# Sensor de Temperatura
exemplo rápido e fácil de como usar o sensor de umidade de solo para projetos IoT.

[![Simular no Tinkercad](https://img.shields.io/badge/Simular%20no-Tinkercad-orange?style=for-the-badge&logo=autodesk)](https://www.tinkercad.com/things/aOurj9iIdDc-sensor-temperatura)


## Como funciona?
O projeto vai utilizar um arduino e o sensor apenas
* Sensor manda dado
* Arduino lê o dado do sensor
* Arduino exibe o dado no terminal

## Materiais nescessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Sensor de Temperatura |
| 1 | ProtoBoard |
| — | Fios de jumper macho-macho |
